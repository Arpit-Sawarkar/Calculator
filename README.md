# 🧮 Python Flask Calculator

A simple and interactive web-based calculator built using **Python Flask, HTML, and CSS**. This project performs basic arithmetic operations through a clean and user-friendly interface.

## 🌐 Live Demo

**[Open Calculator Website](https://arpitcalculator.onrender.com)**

## 🚀 Features

- Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- Clear All (AC) functionality
- Backspace functionality
- Simple and user-friendly interface
- Responsive web interface
- Flask backend integration

## 🛠️ Technologies Used

- **Python** – Backend programming
- **Flask** – Web framework
- **HTML** – Page structure
- **CSS** – Styling and layout
- **Gunicorn** – Production WSGI server
- **Git & GitHub** – Version control and code hosting
- **Render** – Cloud deployment

## ⚙️ Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Arpit-Sawarkar/ArpitCalculator.git
```

2. Navigate to the project folder:

```bash
cd ArpitCalculator
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the Flask application:

```bash
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000/
```
